# Ghostrunner — tear-down

**What it is:** First-person one-hit parkour combat scored like a rhythm game:
sensory input density is extreme but every element is color-coded and
tempo-locked; checkpoints erase friction; Cybervoid upgrades are short
roguelite-flavored power picks between levels.

**Why it works:** Flow state from zero ambiguity — you always know what killed
you. Upgrades between attempts keep failed attempts feeling forward-moving.

**Implementation likelihood:** strict color language; ability picks between
sections; checkpoint granularity tuning.

**In HOLLOW SUN terms:** color law: gold = yours/light/safe-to-graze, red =
hostile, white = overdrive/truth. Dash i-frames + shard return-path create
the "run the blade back through the room" Ghostrunner moment — the *recall*
is our flow verb.

**We deliberately differ:** no platforming precision; our skill ceiling is
geometry (ricochet routes), not reflex timing gates.
