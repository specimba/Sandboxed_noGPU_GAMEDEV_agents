# The Binding of Isaac — tear-down

**What it is:** Room-to-room roguelite where picks are item *synergies*: dozens
of small multipliers (tears, damage, shot speed) that compose into a build you
can *see* change the screen. Item pools + curses + secret rooms create variance;
"the run is the story you tell afterwards."

**Why it works:** Builds are legible on screen — a clip shows the build without
UI. Emergent synergies create "one more run, maybe the combo lands". Rarity
drives stream moments (god-item pulls).

**Implementation likelihood:** stat-block item design (small % multipliers +
flag unlocks like piercing/homing); pool weights; visible build mutation.

**In HOLLOW SUN terms:** boons ARE our Isaac items: +bounces, splash on chain,
twin throws — each must visibly change shard behavior within one encounter.
Synergy rule: every boon touches the shard lifecycle (throw/ricochet/return).

**We deliberately differ:** no room-map exploration — pressure comes from the
arena itself; items never *replace* the throw (no auto-turrets doing the job).
